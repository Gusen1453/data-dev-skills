# 采样与统计规程

目标不是“少查几行”，而是用有限预算尽快发现高风险缺陷，并明确样本能代表什么。`LIMIT` 只限制返回行数，通常不限制底层扫描；没有分区裁剪、索引过滤或引擎原生采样时，`LIMIT 100` 也可能扫完整张表。

## 查询前置门

任何业务数据查询前，先写一张查询卡：

```yaml
purpose: "本次查询要验证什么"
relation: "表、索引、集合或 measurement"
projection: ["只读取必要字段"]
scope:
  time: "明确起止时间"
  entities: "实体集合或确定性抽样规则"
  partitions: "预计命中的分区/分片"
method: "索引过滤 / 分区裁剪 / 原生采样 / 有界聚合"
estimated_cost:
  rows_or_docs: "估计值或 unknown"
  scan_bytes: "估计值或 unknown"
  timeout_seconds: "已批准上限"
  api_calls: "已批准上限"
stop_when: "何时取消，不再扩大范围"
```

以下任一项不清楚时，不直接查业务表：

- 没有时间、分区、实体或索引过滤；
- 不知道 `LIMIT` 是否会减少扫描；
- 不能解释采样方式是否有偏；
- 无法估算代价，也无法设置超时或取消查询；
- 查询计划显示全表扫描且未获明确批准。

先用 `EXPLAIN`、dry run、query profile、分区清单、索引统计、manifest 或引擎等价能力确认裁剪。只读不等于便宜。

## 五阶段漏斗

按阶段推进，不得一开始就对全历史做 `COUNT(*)`、`GROUP BY`、`COUNT DISTINCT`、全字段空值率或全量 join。

### 0. 元数据阶段：不读业务行

先取得：

- 总体量级的已有统计，不为得到精确总行数而另扫全表；
- 分区/分片、最小最大分区、文件数量与大小；
- 主键、索引、排序键、分桶键、向量维度；
- 字段类型、可空性、注释、枚举候选；
- retention、快照、更新时间、水位；
- 查询计划能否命中分区或索引。

这一阶段的输出是“可安全查询的路径”，不是质量结论。

### 1. 侦察阶段：小范围、覆盖边界

选择少量**确定性**样本：

- 时间：最近完整窗口、最早可用窗口、月末/季末、时区或夏令时边界；
- 实体：每个市场/标的类型/来源至少覆盖一组，同时覆盖高频、低频、停牌、退市、未知状态；
- 分区：正常分区、最新分区、历史分区各取代表；
- 字段：先读业务键、时间键、状态、来源和本次假设必需字段，不取整行。

目的：确认真实形态、字段角色与下一步分层，而不是估计总体缺陷率。

### 2. 分层统计阶段：先聚合，不拉明细

按会改变规则适用性的层次统计：

- 市场、交易所、标的类型；
- 日期/月份、数据来源、批次；
- 正常、停牌、退市、未知状态；
- 币种、报告类型、口径、版本。

先返回每层的计数、缺失数、候选重复数、时间范围和极值。只有出现异常的层才下钻明细。

### 3. 定向下钻阶段：异常组取证

对异常层：

1. 缩小到具体实体 × 时间窗 × 来源；
2. 只取解释异常所需字段；
3. 设稳定排序与结果上限；
4. 同时取正常对照组；
5. 保存能推翻当前解释的反证查询。

不要下载大量明细后在本地“肉眼找规律”。

### 4. 扩大或精确阶段：有理由才扩大

只有满足以下条件之一才扩大范围：

- 需要估计缺陷影响面；
- 样本层之间结论矛盾；
- PASS/BLOCK 要求精确计数；
- 用户批准了更高预算。

每次只扩大一个维度：更多实体、更多时间、更多分区或更高精度。扩大前写清“若结果 A/B 分别做什么”；无论结果如何都不改变下一步的查询不应执行。

## 样本怎么抽

### 确定性实体样本

优先使用业务键的稳定哈希分桶，例如：

```text
hash(entity_id) mod 1000 in (7, 31, 203)
```

同一规则跨运行可复现，适合比较质量趋势。必须记录哈希函数、分母和桶号。不要用 `ORDER BY random()` / `rand()`；它常导致全表排序或扫描，且不可复现。

### 分层样本

随机样本容易漏掉小市场、退市标的和异常状态。先按市场、标的类型、来源、状态分层，再在层内做稳定哈希抽样。小层可全取，大层按比例取；报告每层的总体量级和实际样本数。

### 时间样本

时间序列不能只抽随机日期。至少组合：

- **近期连续窗口**：检查时效与近期断档；
- **历史窗口**：检查回补和口径漂移；
- **边界窗口**：月末、季末、年末、财报期、公司行动日前后；
- **特殊窗口**：休市、半日市、夏令时切换、系统故障或供应商切换前后。

连续性检查必须用连续窗口，不能用离散随机日期。

### 极端与异常样本

采样不能只有“正常样本”。主动覆盖：

- 数值 Top/Bottom N；
- 空值率最高的层；
- 记录数最少/最多的实体；
- 最新更新时间最旧的实体；
- 重复次数最多的业务键；
- 枚举值为未知、空或低频值的记录。

这是风险定向样本，不用于估计总体发生率。

### 引擎原生采样

使用 `TABLESAMPLE`、ClickHouse `SAMPLE`、Mongo `$sample`、ES 查询、时序降采样或 ANN 前，先确认实现：

- 是按行、数据块、分片还是主键采样；
- 是否会扫描全量后再抽；
- 是否可复现；
- 是否偏向大文件、大分片或活跃实体；
- 是否返回近似聚合。

不知道实现时，只把结果当侦察样本，不用它估算总体比例或给 PASS。

## 统计什么

不同字段角色使用不同统计，不做“所有列统一跑一遍”。

| 字段/目标 | 第一轮统计 | 第二轮下钻 | 注意 |
|---|---|---|---|
| 业务键 | 组数、候选重复组数 | 重复 Top N 及组内差异 | 精确 distinct 很贵时先用近似值侦察，定级前精确验证异常层 |
| 时间键 | 最早/最晚、每时间桶记录数 | 最大 gap、缺失实体-日期 | 连续性用日历 × 生命周期，不靠全表平均 |
| 关键字段 | 非空数、空值率，按层拆分 | 孤立空值及上下游对照 | 字段不存在与值为 NULL 分开 |
| 数值字段 | min/max、分位数、负数/零数 | 极端样本、跨字段复算 | 平均数常掩盖量级错；优先分位和数量级 |
| 枚举字段 | Top K、低频值、未知/空 | 完整取值域或标准字典差集 | 高基数字段禁止无界 terms/group by |
| 时效字段 | 最新水位、延迟分桶 | 最慢实体/批次及链路分段 | 业务时间与入库时间都要有 |
| 跨表关系 | 分层计数与键覆盖率 | 差集样本、单位比值、复算 | 先把两边各自缩到同一范围，再 join |
| 向量字段 | 维度、空/全零/NaN 计数 | 源文档 id 与向量 id 差集 | ANN 召回不是精确质量统计 |

### 推荐的有界统计组合

一轮统计尽量合并同一范围内可共用扫描的指标，但不要写成超宽查询：

```text
记录数
关键字段空值数
业务时间最小/最大
数值字段最小/最大及少量分位
已确认枚举的 Top K
```

以下通常代价高，必须单独预算：

- 精确 `COUNT(DISTINCT ...)`；
- 高基数全量 `GROUP BY`；
- 无索引排序、窗口函数和跨大表 join；
- 全历史分位数；
- 全文脚本字段计算；
- ES 高基数 terms、Mongo 大 `$lookup`、向量库全量 id 导出。

先用近似 distinct、分区统计、索引统计或分层候选检测缩小范围，再对异常范围做精确查询。

## 全表检查何时允许

全表不是绝对禁止，但必须同时满足：

1. 该检查需要精确总体结论，采样不能回答；
2. 有分区、索引、预聚合或引擎统计可控制代价，或表本身已确认很小；
3. 已获得执行计划/扫描量估算；
4. 用户批准该次预算；
5. 设置超时、取消条件和结果上限；
6. 记录快照或水位，保证结果可复现。

主键唯一性、关键字段全量非空等上线门禁最终可能需要全量验证，但应由持续监控或分区增量检查承担，不应每次人工验收重扫全历史。

## 增量优先

有历史检查记录时，不重复扫已确认且不可变的分区：

- 新增分区：全量检查新分区；
- 可变近期窗口：重查最近若干业务周期，窗口来自回补制度；
- 历史分区：只查发生版本、checksum、manifest 或水位变化的部分；
- 跨分区关系：只检查边界与受影响实体。

报告写清本次是“全范围结论”还是“自上次水位后的增量结论”。

## 统计结论的权限

- 样本里未发现问题，只能写“在所列样本范围内未观察到”，不能写总体 PASS。
- 风险定向样本命中异常，能证明异常存在，但不能直接代表总体发生率。
- 近似统计只能用于侦察和选择下钻范围；用于 PASS/BLOCK 的阈值、分母和违规数必须明确是否精确。
- 统计显著不等于业务错误；业务口径仍需 `CONFIRMED`。
- 每个统计结果都附：数据范围、抽样规则、样本数/总体量级、近似性、引擎与快照、查询耗时与扫描量。

## 执行记录模板

```yaml
sample_id: S-001
population: "目标总体定义"
strata: ["市场", "标的类型", "状态"]
selection:
  method: "稳定哈希 + 连续时间窗 + 风险定向样本"
  rule: "可重跑的选择表达式"
coverage:
  sampled_entities: 0
  population_entities_estimate: 0
  time_range: ["from", "to"]
statistics:
  exact: ["本次精确统计"]
  approximate: ["本次近似统计及误差说明"]
cost:
  elapsed_seconds: 0
  scan_bytes: 0
  rows_or_docs_examined: 0
limitations: ["样本未覆盖什么，不能推出什么"]
```
